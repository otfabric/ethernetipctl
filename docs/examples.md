# Examples

Real runs of ethernetipctl against its own simulated adapter, generated by
[`scripts/examples.sh`](../scripts/examples.sh) (`make examples`): the
adapter runs as `ethernetipctl adapter --listen 127.0.0.1 --io-address
127.0.0.1:2223 --echo --logix` (its I/O on 2223: the commands' I/O endpoint
takes 2222 on the same host),
and every command and its output below are as they were printed (stdout
and stderr together). Timings, session handles and serial numbers change
from run to run; with a real device, replace `127.0.0.1` by its address.

## Discover and identify

One ListIdentity datagram to one address (a broadcast address reaches every device of a segment), then the identity of one device.

### Discover

```console
$ ethernetipctl discover --address 127.0.0.1 --wait 500ms
ListIdentity to 127.0.0.1:44818: 1 device(s) in 503 ms
  127.0.0.1:44818       "ethernetipctl adapter" (vendor 65535 -, Communications Adapter, product 1, rev 1.1, serial 0x00000001)
```

```console
$ ethernetipctl discover --address 127.0.0.1 --wait 500ms --format table
```

## Attributes and objects

## Logix tags (Rockwell, vendor specific)

The adapter's --logix tag database: atomic, array, STRING and structure tags.

### The tag list

```console
$ ethernetipctl tag list 127.0.0.1
Tags of controller scope at 127.0.0.1:44818: 6 (project "OTFabric")
  Count                            DINT             instance 1
  Speed                            REAL             instance 2
  Flags                            DINT             instance 3
  Values[10]                       INT              instance 4
  Name                             STRING           instance 5
  Motors[2]                        Motor            instance 6
```

### Read a tag

```console
$ ethernetipctl tag read 127.0.0.1 Count
Count = DINT[1] at 127.0.0.1:44818 in 0.1 ms
  [0] 42
```

### Write it

```console
$ ethernetipctl tag write 127.0.0.1 Count --type DINT --value 42 --yes
Wrote Count = DINT[1] {42} at 127.0.0.1:44818 in 0.1 ms
```

### Read it back as JSON

```console
$ ethernetipctl tag read 127.0.0.1 Count --format json
{
  "target": "127.0.0.1:44818",
  "connected": false,
  "tag": "Count",
  "type": "DINT",
  "count": 1,
  "data": "2a000000",
  "values": [
    42
  ],
  "rtt_ms": 0.115
}
```

### Read part of an array

```console
$ ethernetipctl tag read 127.0.0.1 Values\[2\] --count 4
Values[2] = INT[4] at 127.0.0.1:44818 in 0.1 ms
  [0] 2
  [1] 3
  [2] 4
  [3] 5
```
